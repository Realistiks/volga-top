# Команда 322 - сайт-портфолио

Базовая версия сайта по образцу личного портфолио: тёмная тема, карточки,
адаптивная сетка, анимации появления при прокрутке и полноэкранный просмотр фотографий.
Капитан расположен в центре, участники появляются с боков по двое при спуске вниз.
Добавлены партиклы за курсором и чат, который через локальный мост передаёт вопросы
в текущую сессию OpenCode и показывает ответ прямо на странице.

## Запуск локально

Откройте `index.html` в браузере. Сайт статический, сервер не нужен.
Для проверки адаптива откройте инструменты разработчика и посмотрите ширину 375 px.

### Чат с ИИ-агентом

Чат на GitHub Pages работает без сервера только как витрина: если мост не запущен,
он отвечает «Удалённый чат неактивен». Чтобы вопросы приходили в текущую сессию
OpenCode, запустите локальный мост:

```bash
python bot/bridge.py
```

Затем откройте **http://127.0.0.1:8765/** - мост отдаёт тот же сайт и чат работает
напрямую. Вопросы вне темы команды отсекаются и к агенту не уходят.

Мост проверяет доступность сессии OpenCode перед каждым запросом. Если агент
недоступен, чат сразу выдаёт «Удалённый чат неактивен» без ожидания.
Порт и сессию можно переопределить переменными `CHAT_BRIDGE_PORT` и
`OPENCODE_SESSION_ID`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `volga-top`.
2. Скопируйте содержимое этой папки в репозиторий.
3. Выполните команды:

```bash
git add .
git commit -m "Базовая версия сайта команды"
git push -u origin main
```

4. В настройках репозитория включите Pages: Settings - Pages - Source: Deploy from a branch - main / root.
5. Готовый адрес сайта: **https://realistiks.github.io/volga-top/**.
   Публичный репозиторий: https://github.com/Realistiks/volga-top.

Файл `.nojekyll` уже лежит в корне и отключает обработку Jekyll.

**Важно по правилам хакатона:** п. 8.1 положение требует размещать код в российской
системе контроля версий, например GitVerse или ином сервисе, согласованном с организатором.
GitHub Pages здесь используется только как публичное зеркало. Основной репозиторий
для жюри нужно завести в российском сервисе и указать ссылку на него в разделе
«Контакты и ссылки» (`id="repo-link"` в `index.html`).
