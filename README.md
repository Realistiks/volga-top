## 2. Реализованное решение

Статический сайт-портфолио команды 322 на базовом HTML. Капитан расположен в центре,
участники появляются с боков по двое при прокрутке. Реализовано:

- адаптивная вёрстка под телефон и печатная версия страницы;
- анимации появления блоков при скролле и полноэкранный просмотр фотографий;
- партиклы-созвездие за курсором и касанием;
- чат с базовыми ответами, работающими без сервера;
- передача небазовых вопросов о команде в открытую сессию OpenCode через локальный
  или удалённый мост с фильтром по теме;
- конструктор персональных промтов для каждого участника;
- обратный отсчёт до сдачи работ 27 ноября 2026, 23:59 МСК.

Как пользоваться: открыть сайт, прокрутить страницу, нажать на фотографию для
полноэкранного просмотра, открыть чат справа внизу и задать вопрос о команде.
Для ответов агента запустить мост по разделу 5.

## 4. Архитектура

Основные компоненты:

- `index.html` - разметка и содержание всех разделов;
- `css/style.css` - базовая тема, сетка, карточки, анимации;
- `css/extra.css` - партиклы, чат, конструктор промтов, обратный отсчёт;
- `js/main.js` - появление блоков через IntersectionObserver и лайтбокс;
- `js/particles.js` - шлейф из точек и линий на canvas;
- `js/answers.js` - локальная база базовых ответов;
- `js/idea.js` - конструктор промтов, таймер, статус агента;
- `js/config.js` - публичный адрес моста;
- `bot/bridge.py` - HTTP-сервер, раздача сайта, фильтр вопросов, вызов OpenCode;
- `bot/start_remote.py` - запуск моста и туннеля.

Движение данных запроса:

```
Посетитель -> чат на сайте -> проверка базовых ответов (js/answers.js)
    -> если ответа нет: POST /ask на мост (127.0.0.1:8765 или HTTPS-туннель)
    -> фильтр темы команды -> POST /api/session/<id>/prompt в OpenCode
    -> POST /api/experimental/session/<id>/wait
    -> GET /api/session/<id>/message -> текст последнего ответа
    -> ответ в чате на странице
```

Если сессия OpenCode недоступна, мост возвращает «Удалённый чат неактивен».

## 5. Установка и запуск

Требования: современный браузер, Python 3.11+, установленный и авторизованный OpenCode,
для удалённого режима - cloudflared.

Просмотр сайта без чата:

```bash
# открыть index.html двойным щелчком
```

Локальный чат:

```bash
python bot/bridge.py
# открыть http://127.0.0.1:8765/
```

Удалённый чат на время тестов:

```bash
python bot/start_remote.py
# новый публичный адрес и отправка конфигурации на GitHub:
python bot/start_remote.py --new-tunnel --push
```

Остановка - Ctrl+C. Порт и сессию можно задать переменными `CHAT_BRIDGE_PORT`
и `OPENCODE_SESSION_ID`, путь к cloudflared - переменной `CLOUDFLARED_BIN`.
