# Команда «Волга.ТОП» - сайт-портфолио

Базовая версия сайта по образцу личного портфолио: тёмная тема, карточки,
адаптивная сетка, анимации появления при прокрутке и полноэкранный просмотр фотографий.
Капитан расположен в центре, участники появляются с боков по двое при спуске вниз.

## Структура и зоны ответственности

| Файл | Отвечает | Что делает |
| --- | --- | --- |
| `index.html` | Ильнур, промты пишет капитан | Разметка, структура разделов, семантика |
| `css/style.css` | Андрей и Никита | Цветовая гамма, карточки, шрифты, адаптив |
| `js/main.js` | Капитан | Анимации появления, полноэкранный просмотр фото |
| `assets/img/` | Капитан | Фотографии команды |
| `README.md` | Капитан | Описание, раскрытие ИИ, инструкция по сдаче |

## Запуск локально

Откройте `index.html` в браузере. Сайт статический, сервер не нужен.
Для проверки адаптива откройте инструменты разработчика и посмотрите ширину 375 px.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `volga-top`.
2. Скопируйте содержимое этой папки в репозиторий.
3. Выполните команды:

```bash
git add .
git commit -m "Базовая версия сайта команды"
git push -u origin main
```

4. В настройках репозитория включите Pages: Settings - Pages - Source: Deploy from a branch - main / root.
5. Адрес сайта будет вида `https://<логин>.github.io/volga-top/`.

Файл `.nojekyll` уже лежит в корне и отключает обработку Jekyll.

**Важно по правилам хакатона:** п. 8.1 положение требует размещать код в российской
системе контроля версий, например GitVerse или ином сервисе, согласованном с организатором.
GitHub Pages здесь используется только как публичное зеркало. Основной репозиторий
для жюри нужно завести в российском сервисе и указать ссылку на него в разделе
«Контакты и ссылки» (`id="repo-link"` в `index.html`).

## Раскрытие использования ИИ

Заполняется капитаном до сдачи, требуется по п. 9.2 положения:

- Инструменты: ИИ-ассистент в чате, промты формулирует капитан (уточнить точное название модели).
- Цели использования: поиск идей, заготовки HTML/CSS, тексты разделов, анимации.
- Созданные или изменённые элементы: каркас `index.html`, начальные стили, скрипт анимаций, черновики текстов.
- Проверка участниками: Ильнур переписал разметку, Андрей и Никита доработали визуал, капитан свёл части и проверил адаптив.
- Каждый участник понимает и умеет объяснить свой вклад (п. 9.3 и п. 6.6).
